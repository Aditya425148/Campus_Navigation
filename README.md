This Python application is a campus navigation tool that allows users to manage and navigate to key locations on their campus using Google Maps. It provides a user-friendly interface for adding, viewing, removing, and opening predefined or custom campus locations.

Features:
Predefined Locations: Includes a list of common campus locations, such as:
Library
Volley Ball Court
Main Building
Mechanical Workshop
Electrical Department
ATM
Hostel

Add Custom Locations: Users can add new locations by specifying their name and Google Maps URL.

View Locations: Displays all saved campus locations with their corresponding URLs.

Navigate Using Google Maps: Opens the selected location directly in the default web browser for easy navigation.

Remove Locations: Allows users to delete unwanted locations from the list.

How to Use:
Run the Program: Start the script to access the campus map tool.
Main Menu:
Open Location in Google Maps: Select a location from the list to open it in Google Maps.
Add a New Location: Add a new location by providing its name and Google Maps link.
Remove a Location: Delete an existing location by selecting it from the list.
View All Locations: Display all saved locations with their details.
Exit: Quit the application when you're done.

Requirements:
Python 3.x
Internet connection to access Google Maps links.
